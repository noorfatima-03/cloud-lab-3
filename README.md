# Cloud Computing Lab 3

## Objective

Implementation of SaaS and PaaS services.

## Project

Student Records Management System.

The application allows users to:

- Add student records
- Store records in a cloud database
- Retrieve records from the cloud database
- Display records in a web browser

## Technologies Used

- HTML
- CSS
- JavaScript
- Netlify
- Netlify Functions
- Supabase Cloud Database
- GitHub

## Architecture

Browser
↓
Netlify
↓
Frontend
↓
Netlify Serverless Function
↓
Supabase Cloud Database

## Files

- index.html - Web page
- style.css - Page styling
- script.js - Frontend JavaScript
- students.js - Backend/serverless function
- netlify.toml - Netlify configuration

## Cloud Services

GitHub is used for source code management.

Netlify is used for application deployment and serverless backend functions.

Supabase is used as the cloud database.
